# LinkedIn skill knowledge (vendored)

Writing knowledge for LinkedIn Studio's DeepSeek prompts, copied from the
MIT-licensed project https://github.com/sergebulaev/linkedin-skills
(Copyright (c) 2026 Sergey Bulaev, see LICENSE). Loaded by
`app/services/linkedin_skill_library.py`; the tool/script instructions in the
SKILL.md files are ignored by the prompts (DeepSeek has no tools) - only the
writing rules, formulas, templates and checklists are used.

Not included: engager-analytics and thread-monitor (they read other members'
engagement, which LinkedIn's official API does not allow without partner
approval).
