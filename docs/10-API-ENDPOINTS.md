# 10 — API ENDPOINTS COMPLETE REFERENCE

## Every Endpoint Explained

---

## Base URL

```
Production: https://hyperclients.online/api
Development: http://localhost:8000/api
```

## Authentication

All endpoints require Bearer token:
```
Authorization: Bearer <supabase_jwt_token>
```

---

## 1. Auth Endpoints (`/api/auth`)

### GET /api/auth/me

**Purpose:** Get current user profile with subscription info.

**Request:**
```http
GET /api/auth/me
Authorization: Bearer <token>
```

**Response:**
```json
{
    "id": "uuid-123",
    "email": "user@example.com",
    "created_at": "2025-01-15T10:30:00Z",
    "subscription": {
        "plan_id": "pro",
        "status": "active",
        "searches_remaining": 15,
        "leads_remaining": 85,
        "ai_calls_remaining": 95
    },
    "is_team_member": false
}
```

---

### GET /api/auth/team

**Purpose:** List team members (Pro/Agency only).

**Response:**

```json
{
```

### POST /api/auth/team

**Purpose:** Add team member.

**Request:**
```http
POST /api/auth/team
Authorization: Bearer <token>
Content-Type: application/json

{
    "username": "john",
```

```json
    "login_credentials": {
        "email": "john@members.hyperclients.online",
        "password": "<auto-generated>"
    }
}
```

## 3. Leads Endpoints (`/api/leads`)

### GET /api/leads

**Purpose:** Get paginated leads with filters.

**Request:**
```http
GET /api/leads?search_id=uuid&source=linkedin&post_type=buyer&category=hot&status=new&page=1&limit=20
Authorization: Bearer <token>
```

**Query Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `search_id` | string | Filter by search |
| `source` | string | "linkedin" or "google_maps" |
| `post_type` | string | "buyer", "hiring", "job_seeker" |
| `category` | string | "hot", "warm" |
| `status` | string | "new", "contacted", "replied", "converted", "lost" |
| `is_favorite` | bool | Only favorites |
| `search` | string | Full-text search |
| `sort_by` | string | "created_at", "ai_confidence_score" |
| `sort_order` | string | "asc", "desc" |
| `page` | int | Page number |
| `limit` | int | Results per page |

**Response:**
```json
{
    "leads": [
        {
            "id": "lead-uuid-1",
            "search_id": "search-uuid-123",
            "full_name": "John Smith",
            "company": "Acme Corp",
            "headline": "CEO at Acme Corp",
            "description": "Looking for website developer...",
            "website_url": "https://acme.com",
            "linkedin_url": "https://linkedin.com/in/johnsmith",
            "post_url": "https://linkedin.com/posts/...",
            "email": "john@acme.com",
            "phone": "+1-555-0123",
            "location": "New York, NY",
            "country_code": "US",
            "post_text": "Looking for a website developer...",

            "lead_type": "explicit_need",

            "ai_pitch": "Hi John, I noticed...",

}
```

## Error Responses

### 400 Bad Request
```json
{
    "detail": "Invalid request body"
}
```

### 401 Unauthorized
```json
{
    "detail": "Not authenticated"
}
```

### 403 Forbidden
```json
{
    "detail": "Upgrade required",
    "upgrade_url": "/pricing"
}
```

### 404 Not Found
```json
{
    "detail": "Search not found"
}
```

### 429 Too Many Requests
```json
{
    "detail": "Daily search limit reached",
    "upgrade_url": "/pricing"
}
```

### 500 Internal Server Error
```json
{
    "detail": "Internal server error"
}
```
